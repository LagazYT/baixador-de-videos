# Componentes de terceiros

O instalador inclui estes programas, cada um com a sua própria licença:

| Componente | Uso | Licença |
|---|---|---|
| [yt-dlp](https://github.com/yt-dlp/yt-dlp) | Download dos vídeos | Unlicense |
| [FFmpeg](https://ffmpeg.org) (via [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg)) | Juntar áudio e vídeo, MP3 | GPL / LGPL |
| [Deno](https://github.com/denoland/deno) | Exigido pelo YouTube | MIT |
| [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter) | Interface | MIT |
| [Pillow](https://python-pillow.org) | Imagens | MIT-CMU |
| [pystray](https://github.com/moses-palmer/pystray) | Ícone na bandeja | LGPL-3.0 |
| [Python](https://www.python.org) | Execução | PSF |
| Fontes [VT323](https://fonts.google.com/specimen/VT323), [Press Start 2P](https://fonts.google.com/specimen/Press+Start+2P) e [Cinzel](https://fonts.google.com/specimen/Cinzel) | Estilos Arcade 8-bit e Fantasia / RPG (pasta `fontes`) | SIL Open Font License 1.1 |

O código-fonte do FFmpeg está disponível em https://ffmpeg.org/download.html.
