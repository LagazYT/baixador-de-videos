Estilo visual

Muda as cores, as formas e as imagens. Clássico é o visual principal; Cyberpunk usa amarelo, vermelho e cinza com cantos retos.

Segundo plano

Os downloads continuam com a tela desligada ou com o app minimizado. O progresso aparece na barra de notificações, com botão para cancelar.

Sugestões de download

Assistindo no YouTube, TikTok, Instagram ou no navegador? Toque em Compartilhar e escolha Baixador de Vídeos: o vídeo já abre aqui pronto para baixar.

Login (vídeos com restrição de idade)

O YouTube só libera vídeos com restrição de idade para quem está logado. Exporte um arquivo cookies.txt de um navegador logado no YouTube (extensão "Get cookies.txt LOCALLY"; o mais fácil é no computador) e envie o arquivo para o celular. Ele fica só neste aparelho.
